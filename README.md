# LinkFit

Protótipo acadêmico de uma plataforma SaaS para conectar alunos e personal trainers.

O projeto foi desenvolvido para a disciplina de Engenharia de Software da Universidade de Mogi das Cruzes (UMC), em 2026.

## Objetivo

O LinkFit organiza em uma mesma interface as rotinas básicas entre aluno e personal:

- busca de profissionais por especialidade;
- agenda semanal de treinos;
- acompanhamento de peso, medidas e metas;
- chat entre aluno e personal;
- painel do personal com alunos, sessões e treinos.

## Como rodar

```bash
npm install
npm run dev
```

Depois acesse o endereço exibido no terminal, normalmente `http://localhost:5173` ou  https://kl1nnn.github.io/LinkFit/

## Telas

- Landing page
- Dashboard do aluno
- Busca de personal trainers
- Agenda semanal
- Evolução física
- Chat
- Dashboard do personal
- Lista de alunos
- Treinos
