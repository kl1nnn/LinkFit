---

## Sobre o Projeto

O **LinkFit** é um protótipo de plataforma SaaS (Software as a Service) que conecta **alunos** a **personal trainers** qualificados. A plataforma centraliza em um único lugar o agendamento de treinos, acompanhamento de evolução física, comunicação via chat e gestão de alunos.

## Funcionalidades

### Aluno
- Buscar personal trainers por nome, especialidade, preço e avaliação
- Visualizar perfil e contratar serviços
- Agendar treinos e visualizar agenda semanal
- Acompanhar evolução física (peso, medidas, gráficos)
- Chat direto com o personal trainer

### Personal Trainer
- Gerenciar lista de alunos e acompanhar progresso
- Visualizar agenda de sessões do dia
- Criar e gerenciar treinos personalizados
- Chat com alunos
- Dashboard com métricas de faturamento e avaliações

## Como Rodar o Projeto

### Pré-requisitos
- [Node.js](https://nodejs.org/) instalado na máquina

### Passo a passo

```bash
# 1. Clone o repositório
git clone https://github.com/seu-usuario/linkfit.git

# 2. Entre na pasta do projeto
cd linkfit

# 3. Instale as dependências
npm install

# 4. Rode o servidor de desenvolvimento
npm run dev
```

Acesse no navegador: `http://localhost:5173`

## Telas do Protótipo

- **Landing Page** — Apresentação da plataforma com CTA para aluno e personal
- **Dashboard do Aluno** — Visão geral de treinos, metas e evolução
- **Buscar Personal** — Lista de trainers com filtros e busca
- **Agenda** — Calendário semanal de treinos
- **Evolução Física** — Gráficos e medidas corporais
- **Chat** — Comunicação entre aluno e personal
- **Dashboard do Personal** — Gestão de alunos, sessões e faturamento
- **Meus Alunos** — Cards com progresso individual
- **Treinos** — Fichas de exercícios por aluno

## Metodologia

O projeto foi desenvolvido seguindo os princípios do **Scrum**, com divisão de papéis entre PO, Scrum Master e equipe de desenvolvimento. O levantamento de requisitos foi realizado por meio de uma **Matriz CDS** (Certezas, Dúvidas e Suposições).
